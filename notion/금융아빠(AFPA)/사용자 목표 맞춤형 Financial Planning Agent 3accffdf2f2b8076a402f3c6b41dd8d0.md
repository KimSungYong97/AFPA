# 사용자 목표 맞춤형 Financial Planning Agent

## 목적

사용자의 현재 금융 상태와 목표를 분석하여 **목표 달성을 위한 실행 가능한 금융 전략(Action Plan)** 을 생성한다.

---

## 입력

- 사용자 정보 : [사용자 금융 프로필](%EC%82%AC%EC%9A%A9%EC%9E%90%20%EA%B8%88%EC%9C%B5%20%ED%94%84%EB%A1%9C%ED%95%84%203abcffdf2f2b80698ba5eec31d3ece16.md)
    - 금융 프로필
    - 목표
    - Life Event
- 외부 정보 : [사용자 목표 관련 금융 정보 수집](%EC%82%AC%EC%9A%A9%EC%9E%90%20%EB%AA%A9%ED%91%9C%20%EA%B4%80%EB%A0%A8%20%EA%B8%88%EC%9C%B5%20%EC%A0%95%EB%B3%B4%20%EC%88%98%EC%A7%91%203accffdf2f2b80e1bcaed3e74a3ce158.md)
    - 금융상품 정보
    - 금융 정책 및 규제
    - 금리 정보

---

## 구조

**통합 플래너 하나가 도메인 모듈(예·적금, 대출·부동산, 투자)을 선택지로 호출**하고, 규제·제도 규칙 엔진이 가능 여부를 판정한다. 도메인별 기능을 따로 만들어 합치지 않는다.

## 주요 기능 (구현 순서)

### 1차 — 기본 분석 (플랫폼 기능)

- 수입 / 지출 분석: 소비 카테고리 분류, 월별·고정/변동 분석, 소비 패턴
- 자산 현황 분석: 자산 분포·비율 시각화, 현금 흐름

### ✅ 2차 — 통합 플래너 (agent 시작)

- 목표별 자산 성장 경로
- 시나리오(What-if): 저축 변경, 지출 이벤트, 소득 변화, 목표 변경
- Action Plan: 지출 개선(불필요한 소비 탐지, 절약 항목, 목표 대비 소비), 자산 리밸런싱(현금·예금·비상금·투자 비중)
- 이행 추적과 경로 이탈 재계산

### 3차 — 규제·제도 엔진 + 예·적금 전략

- 규칙 엔진: DSR/LTV, 자격 요건, 세제(ISA·IRP·연금저축)
- 사용자 목표에 맞는 예·적금 추천, 금리·우대금리 비교, 만기 시뮬레이션, 예·적금 리밸런싱

### 4차 — 대출·부동산 전략

- 구매력 분석, 전세·월세·매매 비교, 청약·정책 상품
- 대출 상품 비교, 상환 전략, DSR/LTV, 정부 정책 반영, 대출 가능성 분석

### 5차 — 투자 전략

- 투자 성향 분석, 자산 배분, 리밸런싱, 연금·절세 포트폴리오
- **(※ 투자 종목 추천이 아니라 자산 배분 중심)**

### 6차 — 자율성 고도화

- 선제 제안, 자율 수준 설정(제안만/소액 자동/승인 후 실행), 이행 이력 기반 개인화

---

## 출력

- Action Plan 생성
    - 사용자의 목표 달성을 위한 실행 가능한 금융 전략 생성
- 추천 결과와 함께 근거 제공
    - 추천 이유 설명
    - 사용자 상황 기반 분석
    - 금융상품 비교
    - 정책 및 규제 반영 내용(적용 규칙·기준일)

---

## Financial Planning Roadmap

- [ ]  1차 : 기본 분석 (수입/지출, 자산 현황)
- [ ]  2차 : 통합 플래너 (경로, 시나리오, Action Plan, 이행 추적)
- [ ]  3차 : 규제·제도 엔진 + 예·적금 전략
- [ ]  4차 : 대출·부동산 전략
- [ ]  5차 : 투자 전략
- [ ]  6차 : 자율성 고도화
