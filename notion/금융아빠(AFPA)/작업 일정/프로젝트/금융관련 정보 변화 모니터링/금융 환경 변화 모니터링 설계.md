# 금융 환경 변화 모니터링 설계

> AFPA(AI Financial Planning Agent) — 금리·상품·정책 변화 감지와 사용자 영향도 계산 설계
> 상태: **초안** (기획 문서 기반 정리. 세부 값·기준은 팀 논의 후 확정)

---

## 1. 개요

사용자 목표·계획에 영향을 줄 수 있는 **외부 금융 환경 변화**를 감지하고, 개인별 영향도를 계산해 알린다. 변경 이력은 「금융 정보 수집」의 변경 추적 결과를 입력으로 받는다.

## 2. 모니터링 대상과 영향 판단

| 대상 | 영향받는 사용자 (판정 기준 안) |
| --- | --- |
| 금리 변경 | 해당 금리 상품 보유자·가입 계획 목표 보유자 |
| 금융상품 변경 | 보유 상품과 동일·유사 상품군 사용자 |
| 카드 혜택 변경 | 해당 카드 보유자, 혜택 카테고리 지출이 큰 사용자 |
| 대출 규제 변경 | 대출 보유자·대출 계획 목표 보유자 |
| 정부 정책 변경 | 자격 요건(연령·소득·거주)에 해당하는 사용자 |
| 청년 지원 정책 변경 | 청년 연령대 사용자 |

## 3. 처리 흐름

1. 변경 감지 (이전 버전 대비 diff)
2. 대상 사용자 매칭 (프로필·보유 상품·목표 기반)
3. 영향도 계산: 예) 금리 변동 → 목표 달성 시기 변화, 월 이자 차이
4. 임계치 초과 시 알림 생성 → 「계획 재설계」 트리거

## 4. 영향도 지표 (안)

- 금전 영향 = 변화 전후 예상 이자·비용 차이 (원/월)
- 일정 영향 = 목표 달성 시기 변화 (개월)
- 중요도 = 금전·일정 영향 크기에 따른 등급(높음/중간/낮음)

## 5. 출력 예

- "현재 가입 가능한 적금보다 더 높은 금리의 상품이 출시되었습니다."
- "대출 규제가 변경되어 기존 계획에 영향이 있습니다."

## 6. 미결 사항

- **착수 시점:** 3차 (금융 정보 수집의 변경 추적에 의존)
- **알림:** 「알림 설계」의 환경 변화 유형·빈도 제한을 따른다.
- **감지 주기:** 금리·상품은 일 1회 배치, 정책·규제는 주 1회부터 시작(소스 갱신 주기에 맞춰 조정)
