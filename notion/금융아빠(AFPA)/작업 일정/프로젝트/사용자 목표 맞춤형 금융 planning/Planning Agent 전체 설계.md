# Planning Agent 전체 설계

> AFPA(AI Financial Planning Agent) — 통합 플래너와 도메인 모듈 구조
> 상태: **초안**. 단계 정의는 「AFPA 로드맵 및 구현 순서」가 기준이다.

---

## 1. 개요

사용자의 현재 금융 상태와 목표를 분석해 **자산을 안정적으로 늘려 가는 실행 가능한 경로(Action Plan)** 를 만들고, 이행을 추적하며, 상황 변화에 맞춰 갱신한다.

핵심 구조: **통합 플래너 하나가 도메인 모듈을 선택지로 호출하고, 규칙 엔진이 가능 여부를 판정한다.** 도메인별 기능을 따로 만들어 나중에 합치지 않는다.

## 2. 구성 요소

```
                        ┌───────────────────────────┐
  사용자 금융 프로필 ──▶ │       통합 플래너 (2차)      │ ◀── 목표 관리
                        │  경로 · 시나리오 · Action Plan │
                        │  · 이행 추적 · 재계산        │
                        └──────┬─────────────┬───────┘
             선택지(Option)    │             │   가능 여부 판정
   ┌──────────────┬────────────┴───┐    ┌────┴───────────────────┐
   │ 예·적금 (3차) │ 대출·부동산 (4차)│    │ 규제·제도 규칙 엔진 (3차) │
   │              │ 투자 (5차)      │    │ 대출 규제·자격·세제      │
   └──────────────┴────────────────┘    └────────────────────────┘
         ▲ 외부 정보 수집 (3차~)                 ▲ 변화 감지 (3차~)
                        │
              자율성 고도화 (6차): 선제 제안 · 개인화 · 자율 수준 설정
```

| 구성 요소 | 차수 | 역할 |
| --- | --- | --- |
| 기본 분석 | 1차 | 수입·지출·자산 분석 (agent 이전, 플랫폼 기능) |
| **통합 플래너** | 2차 | 자산 성장 경로, 시나리오, Action Plan, 이행 추적 |
| **규칙 엔진** | 3차 | 대출 규제·자격 요건·세제 판정 |
| 예·적금 모듈 | 3차 | 상품 선택지, 세후 효과 |
| 대출·부동산 모듈 | 4차 | 구매력, 전세·월세·매매 비교, 대출 전략 |
| 투자 모듈 | 5차 | 자산 배분, 절세 포트폴리오 |
| **자율성** | 6차 | 선제 제안, 자율 수준, 개인화 |

## 3. 입출력

| 구분 | 내용 |
| --- | --- |
| 입력(내부) | 금융 프로필, 목표, Life Event, 이행 이력 |
| 입력(외부, 3차~) | 금융상품·금리·정책·규제·시세 (「금융 정보 수집」) |
| 출력 | 목표별 경로, Action Plan, 추천 근거(이유, 상황 분석, 비교, 적용 규칙·기준일), 이행 현황 |

## 4. Action Plan 구조

| 필드 | 설명 |
| --- | --- |
| action_type | 소비 절감 / 저축 금액 조정 / 자산 비중 조정 / (3차~) 예·적금 변경 / (4차~) 대출 전략·부동산 / (5차~) 투자 비중 |
| description | 실행 내용 |
| path_effect | 목표 달성 시기·부족 자금 변화 (코드 계산) |
| rationale | 추천 이유 (LLM 설명 + 근거 수치 + 규칙 ID) |
| priority | 실행 우선순위 |
| status | 제안 → 수락 → 완료 / 거절 / 만료 |

## 5. 에이전트 구성

- **Planner:** 프로필·목표 → 경로 → Action Plan 구성
- **계산 도구(Tools):** 경로·시나리오·규칙 판정은 코드(결정적). 설명·근거 생성은 LLM
- **Replanner:** 모니터링 이벤트·이행 이탈 시 재계산 (「계획 재설계」)
- **Proactive (6차):** 선제 트리거 감지와 제안 (「6차 자율성 고도화 설계」)

## 6. 차수별 문서

| 차수 | 프로젝트 | 설계 문서 |
| --- | --- | --- |
| 1차 | planning-1차 | 1차 기본 분석 설계 |
| 2차 | planning-2차 | 2차 통합 플래너 설계 |
| 3차 | planning-3차 | 3차 규제·제도 엔진 및 예·적금 설계 |
| 4차 | planning-4차 | 4차 대출·부동산 전략 설계 |
| 5차 | planning-5차 | 5차 투자 전략 설계 |
| 6차 | planning-6차 | 6차 자율성 고도화 설계 |

## 7. 미결 사항

- 통합 플래너의 경로 모델 정밀도(2차 단순 가정 → 3차 이후 실제 상품 효과로 교체하는 시점)
- 도메인 모듈 간 충돌 해결(예: 투자 여력과 대출 상환 우선순위) 규칙
- 사용자별 복수 목표에서의 선택지 조합 탐색 방식
