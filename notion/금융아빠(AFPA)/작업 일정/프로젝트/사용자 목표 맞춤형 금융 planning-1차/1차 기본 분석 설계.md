# 1차 기본 분석 설계

> AFPA — 일반 금융 플랫폼 수준의 수입·지출·자산 분석 (agent 기능은 2차부터)
> 상태: **초안**

---

## 1. 개요

1차는 마이데이터와 금융 프로필을 **보기 좋게 분석해 보여 주는 단계**다. 제안(Action Plan)이나 자산 조정은 하지 않는다. 입력은 「금융 프로필 산출 로직」과 「데이터 자동 분류 로직」의 결과이며, 이 분석 결과는 2차 통합 플래너의 기초 데이터가 된다.

## 2. 수입 / 지출 분석

- **소비 카테고리 분류:** 식비·카페 / 쇼핑·생필품 / 교통·차량 / 취미·문화·기타 (분류 로직 결과 사용)
- **월별 소비 분석:** 월별 총지출·카테고리별 추이
- **고정/변동 지출 분석:** 고정지출 비중, 변동지출 비중
- **소비 패턴 분석:** 요일·시간대·가맹점 빈도
- **수입 분석:** 정기·공적·금융·비정기 수입 구분과 월별 추이

## 3. 자산 현황 분석

- **자산 분포:** 현금성 / 저축성 / 투자 / 연금 자산별 금액·비율
- **자산 비율 시각화:** 도넛/막대 차트
- **부채 현황:** 대출·카드 결제 예정액 (1차는 카드 중심, 대출 상세는 3차)
- **순자산:** 총자산 − 총부채
- **현금 흐름:** 월 가용 소득, 월 여유 자금(Net Cash Flow)

## 4. 진단 결과 표시

- 금융 건강도·금융 잠재력 점수와 4대 지표, 이상 지출(P-05) **표시**
- 이상 지출은 "발견"까지만 하고 절감 제안은 2차에서 한다.

## 5. 제외 (2차로 이관)

| 기능 | 이유 |
| --- | --- |
| 불필요한 소비 탐지 → 절약 항목 추천, 목표 대비 소비 분석 | 목표·경로와 결합된 제안이므로 통합 플래너 |
| 자산 리밸런싱(현금·예금·비상금·투자 비중 제안) | Action Plan 생성이므로 통합 플래너 |

## 6. 출력

- 소비·수입·자산 요약 화면, 카테고리별 차트, 프로필 점수

## 7. 미결 사항

- 차트 구성과 화면 항목(Test UI와 연계)
- 소비 패턴 분석의 시간·요일 단위 필요 여부
