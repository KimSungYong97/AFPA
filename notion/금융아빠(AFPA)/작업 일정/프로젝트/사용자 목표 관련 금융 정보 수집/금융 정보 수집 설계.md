# 금융 정보 수집 설계

> AFPA(AI Financial Planning Agent) — 사용자 목표 달성에 필요한 외부 금융 정보의 수집·필터링·변경 추적 설계
> 상태: **초안** (기획 문서 기반 정리. 세부 값·기준은 팀 논의 후 확정)

---

## 1. 개요

Planning Agent가 사용하는 **외부 정보**(상품·정책·시장 정보)를 수집해 목표 맞춤형으로 제공한다. 사용자 내부 데이터(마이데이터)는 「금융 프로필」이 담당하고, 이 모듈은 외부 데이터만 다룬다.

## 2. 수집 대상

| 구분 | 예시 | 주 사용처 |
| --- | --- | --- |
| 금융상품 | 예금, 적금, 카드, 대출 | planning 2차(예·적금), 3차(대출) |
| 정책 | 청년 정책, 부동산 정책, 정부 지원 정책 | 자격 요건 필터링, 정책 반영 |
| 시장 정보 | 기준금리, 대출금리, 예금금리 | 금리 비교, 시뮬레이션 |
| 기타 | 등… (추후 확장) | |

## 3. 처리 흐름

1. **수집:** 소스별 수집기(API / 검색)가 원본 데이터 확보
2. **정규화:** 소스별 포맷 차이를 공통 스키마로 변환 (상품명, 금리, 조건, 출처, 수집일시)
3. **필터링:** 사용자 목표·금융 프로필(연령, 고용형태, 거주형태 등)로 적용 가능한 항목만 선별
4. **저장 및 변경 추적:** 이전 수집본과 비교해 변경분을 기록 → 「금융관련 정보 변화 모니터링」에 전달
5. **제공:** 사용자 맞춤 금융 정보를 Planning Agent에 전달

## 4. 주요 기능

- **실시간 정보 검색:** 필요 시점에 최신 정보 조회 (캐시 유효기간 내에서는 재사용)
- **목표 기반 정보 필터링:** 목표 유형(주택, 결혼, 은퇴, Life Event)별 관련 정보 매핑
- **변경 사항 추적:** 항목별 이력(버전) 저장, 변경 감지 시 이벤트 발생

## 5. 데이터 모델 (안)

| 필드 | 설명 |
| --- | --- |
| item_id | 수집 항목 식별자 |
| category | PRODUCT / POLICY / MARKET |
| source | 출처(기관·URL) |
| payload | 정규화된 본문 (금리, 조건 등) |
| collected_at | 수집 일시 |
| version / prev_version | 변경 추적용 |

## 6. 출력

- 사용자 맞춤 금융 정보 (목표별 정렬, 출처·기준일 포함)

## 7. 미결 사항

- 수집 소스 확정 (금융상품한눈에, 한국은행 ECOS, 정부24 등 공공 API 사용 여부)
- **착수 시점 확정:** 1·2차는 외부 데이터를 쓰지 않으므로 이 모듈은 **3차**(규제·제도 엔진 + 예·적금)에 착수한다. 2차에서는 도메인 모듈 인터페이스(선택지 규격)만 정의한다.
- 정보 신선도 기준 (갱신 주기)
- 출처 표기 및 이용약관 확인
