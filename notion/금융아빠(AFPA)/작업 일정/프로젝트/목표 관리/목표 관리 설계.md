# 목표 관리 설계

> AFPA(AI Financial Planning Agent) — 목표 CRUD·우선순위·필요 자금·달성 가능성 분석 설계
> 상태: **초안** (기획 문서 기반 정리. 세부 값·기준은 팀 논의 후 확정)

---

## 1. 개요

사용자의 장기 목표와 Life Event를 관리하고, 금융 프로필과 결합해 달성 가능성을 판단한다. 결과는 Planning Agent의 입력이 된다.

## 2. 목표 유형

| 유형 | 예시 | 특성 |
| --- | --- | --- |
| 장기 목표 | 내 집 마련, 결혼, 은퇴 준비 | 큰 금액, 긴 기간 |
| Life Event | 여행, 차량 구매, 노트북 구매 | 단기, 비교적 소액 |

## 3. 데이터 모델 (안) — `goals`

| 필드 | 설명 |
| --- | --- |
| goal_id (PK), user_id (FK) | 식별자 |
| type | LONG_TERM / LIFE_EVENT |
| title | 목표명 |
| target_amount | 목표 금액 |
| target_date | 목표 시점 |
| current_amount | 현재 모인 금액 (선택) |
| priority | 우선순위 (1이 최상) |
| status | ACTIVE / ACHIEVED / PAUSED / DELETED |
| created_at, updated_at | 메타 |

## 4. 기능 설계

- **생성·수정·삭제:** 삭제는 soft delete 권장 (재설계 시 이력 참조)
- **우선순위 설정:** 사용자 지정 순서. 목표 간 충돌(월 가용 예산 초과) 시 경고
- **필요 자금 계산:**
  - `부족 금액 = 목표 금액 − 현재 모인 금액`
  - `월 필요 저축액 = 부족 금액 / 남은 개월 수` (금리 미반영 단순형, 이후 복리 반영)
- **달성 가능성 분석:** 우선순위 순으로 월 가용 예산(금융 프로필의 Net Cash Flow)을 배분
  - 모든 목표의 월 필요액 합 ≤ 여유 자금 → 달성 가능
  - 초과 시 → 부족 자금, 예상 달성 시기(현 배분액 기준) 산출

## 4-1. 필요 자금 계산의 단계적 고도화

| 단계 | 방식 | 비고 |
| --- | --- | --- |
| 1차 | 단순형 `부족 금액 / 남은 개월 수` (금리·물가 미반영) | 외부 데이터 없이 동작 |
| 3차 | 복리 반영: 예·적금 금리 적용 시 월 필요액 감소분 계산 | 금융 정보 수집 연계 |
| 이후 | 물가상승률 반영(실질 목표 금액), 목표 금액 시세 추정(주택 등) | 외부 데이터 필요 |

> 단순형은 월 필요액을 과대 추정하므로 **보수적(안전한) 방향**이다. 화면에 "금리·물가 미반영" 문구를 표기한다.

## 4-2. 목표 금액 입력 방식

1차는 **사용자 직접 입력**만 지원한다. 시세 기반 추정은 외부 데이터가 필요하므로 4차(부동산) 이후다.

## 4-3. 우선순위

사용자 지정이 기본이다. 지정이 없으면 **기한이 가까운 순 → 금액이 작은 순**을 기본값으로 제안한다(제안일 뿐 자동 확정하지 않음).

## 4-4. 목표 유형 분화

| 유형 | 입력 항목 | 도입 |
| --- | --- | --- |
| 일반 목표 / Life Event | 목표명, 금액, 기한, 우선순위 | 1차 |
| 은퇴 | 목표 연령, 희망 월 생활비(→ 필요 자산 환산) | 2차 이후 검토 |
| **부동산(내 집 마련)** | 희망 지역·주택 유형, 매매/전세/월세 의향, 가격대(범위), 목표 시점 | **4차** (구매력 분석·대출·청약과 연동) |

부동산 목표는 가격대와 구매력 분석 결과의 차이를 **부족 자금**으로 환산해 일반 목표와 같은 경로에 반영한다(「4차 대출·부동산 전략 설계」).

## 4-5. 1차와 2차의 관계

- **1차:** 달성 가능성 분석(단순형)까지 — 목표별 필요 월 저축액, 가능 여부, 부족 자금
- **2차:** 통합 플래너가 목표들을 **하나의 자산 성장 경로**로 묶어 시나리오·Action Plan·이행 추적을 제공(「2차 통합 플래너 설계」)

## 5. 출력

- 목표 리스트 / 목표 달성 예상 시기 / 부족 자금

## 6. 미결 사항

- 목표 간 월 배분 비율을 우선순위 순차 배분 외에 비율 배분으로도 지원할지
- 금융 프로필 '금융 잠재력'의 목표 진척 속도 지표(`(월 목표배분액×12)/남은 금액`)와 이 문서의 월 필요 저축액 계산 단위 일원화 (월 단위로 통일 권장)
