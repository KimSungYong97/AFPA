# 4차 대출·부동산 전략 설계

> AFPA — "내 집 마련"을 중심으로 한 대출·부동산 통합 전략
> 상태: **초안**. 규제·제도 규칙 엔진(3차)과 부동산 데이터가 선행 조건이다.

---

## 1. 개요

부동산은 대출 규제, 청약, 세제, 저축 경로가 모두 얽히는 영역이다. 4차는 대출 단독 기능이 아니라 **부동산 목표를 달성하는 하나의 흐름**으로 설계한다. 모든 판정은 규칙 엔진, 경로 반영은 통합 플래너가 맡는다.

## 2. 부동산 목표 흐름 (내 집 마련)

```
① 구매력 분석      가능한 가격대 = 자기자본 + 대출 가능 한도(규칙 엔진)
② 선택지 비교      전세 / 월세 / 매매 (총비용·자금 부담)
③ 취득 비용 포함 자금 계획   취득세·중개보수·등기비용·이사비
④ 자금 조달 계획   저축 경로 + 대출 구성 + 청약·정책 상품
⑤ 시점 최적화      "지금 vs N년 뒤" 시나리오 비교 (통합 플래너)
⑥ 이행·갱신        규제 변경·소득 변화 시 재계산
```

## 3. 구매력 분석

- **자기자본:** 순자산 중 목표에 배정 가능한 금액(비상금 제외, 처분 가능 자산 기준)
- **대출 가능 한도:** `loan_capacity` (DSR·LTV·대출 종류별 규제, 사용자 소득·기존 대출 반영)
- **가능 가격대:** 자기자본 + 대출 한도 − 취득 비용
- **여유 검증:** 상환 후 월 여유 자금이 최소 기준 아래로 떨어지지 않는지(건강도 하락 방지)
- 입력 지역·주택 유형에 따른 규제 차등은 규칙표에서 처리

## 4. 전세·월세·매매 비교

| 비교 항목 | 내용 |
| --- | --- |
| 초기 필요 자금 | 보증금, 계약금·잔금, 취득 비용 |
| 월 부담 | 월세, 대출 이자·원리금, 관리비 |
| 기회비용 | 묶이는 자금의 대안 수익(예·적금 금리) |
| 총비용(N년) | 보유 기간별 총지출 비교 |
| 제약 | 규제·자격(전세대출 요건, 정책 상품 대상 여부) |

> 가격 변동(시세 상승·하락)은 예측하지 않고 **시나리오 가정**(사용자·기본값)으로 비교한다.

## 5. 대출 전략

- **대출 상품 비교:** 금리(고정/변동), 한도, 중도상환수수료, 자격 요건(청년·생애최초 등 정책 상품 포함)
- **상환 전략:** 방식(원리금균등·원금균등·만기일시)별 총이자, 다중 대출 시 상환 순서(고금리 우선 등), 중도상환 시 효과
- **DSR/LTV 반영:** 규칙 엔진 판정을 그대로 사용(이 문서에 수치를 고정하지 않음)
- **대출 가능성 분석:** 규제 한도 내 예상 가능액, 소득·부채 변화에 따른 민감도

## 6. 청약·정책 상품

- 청약 자격·가점·납입 현황 추적(해당 시 마이데이터의 청약 계좌 활용)
- 정책 대출·상품의 자격 판정(`eligible_products`)과 신청 시점 안내

## 7. 목표 유형 분화

부동산 목표는 일반 목표와 입력 항목이 다르다(「목표 관리 설계」 참조).
- 희망 지역·주택 유형, 매매/전세/월세 중 의향, 목표 시점, 가격대(범위)
- 구매력 분석 결과와 희망 가격대의 차이를 **부족 자금**으로 환산해 경로에 반영

## 8. 데이터 요구

| 데이터 | 용도 | 확보 방식 |
| --- | --- | --- |
| 마이데이터 대출·연금·보험 | 기존 부채 반영, 자산 정확도 | 3~4차 도입 |
| 지역별 시세·실거래 | 가격대 설정, 시나리오 | 공공 데이터(소스 3차 착수 전 확인). 초기엔 사용자 입력·구간 값 |
| 규제·세제 규칙 | 한도·비용 | 규칙 엔진 |

## 9. 출력

- 가능 가격대와 근거(적용 규제·기준일), 선택지 비교표, 자금 조달 계획, 목표 경로 반영, 시나리오 비교

## 10. 미결 사항

- 시세 데이터 소스와 갱신 주기, 초기 범위(전국 vs 특정 지역)
- 규제의 지역·주택 수 차등 반영 깊이
- 경매·분양 등 비일반 거래 제외 여부
- 부동산 관련 표현의 규제 검토(투자 권유 해석 방지)
