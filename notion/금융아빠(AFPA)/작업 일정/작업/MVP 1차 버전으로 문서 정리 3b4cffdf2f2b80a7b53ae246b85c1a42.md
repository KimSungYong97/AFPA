# MVP 1차 버전으로 문서 정리

담당자: 김주영
진행 상태: 진행 중
마감일: 2026년 8월 11일

#### 1차 : 기본 금융 플랫폼

- 사용자 자산(예/적금 + 카드 + 투자) 연동·입력
- 자동 분류와 금융 프로필 생성(건강도·잠재력)
- 수입·지출·자산 분석
- 목표 입력·관리·달성 가능성(단순형)

#### 2차 : 통합 플래너 (agent 시작)

- 목표별 자산 성장 경로, 시나리오(What-if)
- Action Plan(소비 절감·저축 조정·자산 리밸런싱), 이행 추적
- 소비 변화 모니터링, 단순 재설계

#### 3차 : 규제·제도 엔진 + 예·적금

- 규제·제도 규칙 엔진(DSR/LTV, 자격 요건, 세제), 대출 데이터 수집 추가
- 예·적금 외부 데이터 수집, 사용자 목표에 맞는 예·적금 추천, 시뮬레이션
- 금융 환경 변화 모니터링

#### 4차 : 대출·부동산

#### 5차 : 투자 자산 배분

#### 6차 : 자율성 고도화 (선제 제안·개인화)
