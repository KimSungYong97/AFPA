# 알림 설계

> AFPA — 소비 변화·금융 환경 변화·계획 재설계가 공통으로 사용하는 알림 규칙
> 상태: **초안**. 임계치는 「설계 파라미터 결정표」와 함께 튜닝한다.

---

## 1. 목적

모니터링 결과를 사용자가 **행동할 수 있는 형태**로 전달한다. 알림이 많으면 무시되므로, 빈도 제한과 우선순위를 둔다.

## 2. 알림 유형

| 유형 | 발생원 | 예시 | 사용자 액션 |
| --- | --- | --- | --- |
| 소비 변화 | 소비 변화 모니터링 | "식비가 3개월 평균보다 28% 늘었어요" | 확인 / 일회성 지정 |
| 환경 변화 | 금융 환경 변화 모니터링 (3차~) | "더 높은 금리의 적금이 출시되었어요" | 상세 보기 |
| 계획 재설계 제안 | 계획 재설계 | "월 저축액을 10만 원 줄여도 목표 달성이 가능해요" | **승인 / 거절** |
| 이행·경로 이탈 | 통합 플래너 이행 추적 (2차~) | "이번 달 저축 계획 대비 15만 원 부족해요" | 재계산 제안 보기 |
| 선제 제안 | 자율성 (6차) | "세액공제 한도가 남아 있어요, 연말 전에 채우면 환급이 늘어요" | 승인 / 거절 |
| 목표 마일스톤 | 목표 관리 | "목표의 50%를 달성했어요" | 확인 |

## 3. 채널

| 단계 | 채널 |
| --- | --- |
| 1~2차 | 앱(웹) 내 알림 센터 |
| 이후 | 푸시, 이메일 (사용자 설정으로 선택) |

## 4. 우선순위와 빈도 제한

| 등급 | 조건(안) | 전달 방식 |
| --- | --- | --- |
| 높음 | 계획 재설계 제안, 목표 달성 시기 ±2개월 이상 변화, DSR 40% 초과 | 즉시 |
| 중간 | 구조적 소비 변화, 유리한 상품 출시 | 일일 요약에 포함 |
| 낮음 | 마일스톤, 일시적 변화 참고 | 주간 요약 |

**빈도 제한(안):** 즉시 알림은 하루 최대 1건, 일일 요약 1회, 같은 이벤트는 7일간 재알림 안 함.
**사용자 설정:** 유형별·카테고리별 끄기 지원. 높음 등급 중 재설계 제안은 끌 수 없다(승인 흐름이 필요하므로).

## 5. 알림 메시지 구조

1. **현상:** 무엇이 변했는가 (수치 포함)
2. **영향:** 목표·여유 자금에 미치는 영향 (예: 달성 시기 2개월 지연)
3. **제안:** 선택 가능한 행동 (승인/거절 버튼)
4. **근거:** 비교 기간·계산 근거 한 줄, 「더 보기」로 상세 연결

## 6. 소비 변화 알림 발송 조건

「소비 변화 모니터링 설계」의 일시/구조 판정 결과 **구조적**인 경우만 알림 대상이다. 일시적 변화는 낮음 등급(주간 요약)으로 내린다.

## 7. 재설계 제안의 승인 흐름

- 제안은 **자동 적용하지 않는다.** 사용자 승인 후에만 기존 계획 버전을 교체한다.
- 거절 시 같은 사유의 제안은 30일간 재제안하지 않는다.
- 미응답은 거절과 동일하게 처리하지 않고 계획을 유지하며, 7일 후 한 번 리마인드한다.

## 8. 미결 사항

- 푸시·이메일 도입 시점과 수신 동의 문구
- 일일 요약 발송 시간대
