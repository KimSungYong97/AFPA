# 평가 기준 및 성능 대시보드

> AFPA — 분류·산출·Action Plan의 품질을 어떻게 검증하고 무엇을 모니터링할지
> 상태: **초안**. 목표 수치는 초기 가설이며 테스트 데이터 결과를 보고 조정한다.

---

## 1. 평가 대상

| 대상 | 방법 | 기준(초기 목표) |
| --- | --- | --- |
| 데이터 자동 분류 | 정답 라벨이 있는 테스트 데이터로 정확도 측정 | 대분류 정확도 **95%+**, 변동지출 카테고리 **90%+** |
| 주기성 감지(수입·고정지출) | 정답 라벨 대비 재현율·정밀도 | 정기수입 재현율 **95%+**, 고정지출 정밀도 **90%+** |
| 프로필 산출 | 수기 계산한 골든 케이스와 비교 | 지표 값 오차 **0** (결정적 계산) |
| 목표 달성 가능성 | 경계 케이스 단위 검증 | 여유 자금=필요액 등 경계에서 일관된 판정 |
| Action Plan 품질 | 체크리스트 평가(아래 3절) | 필수 항목 100% 충족 |

## 2. 테스트 데이터 활용

- 직접 제작한 테스트 사용자(user_001~003, 페르소나별)를 기준 데이터로 쓴다.
- 각 사용자의 거래에 **정답 카테고리·주기성 라벨**을 별도로 유지한다(분류 로직 입력에는 포함하지 않음).
- 페르소나 다양성: 사회초년생(소득 낮음·저축 여력 높음), 중간 자산, 은퇴 임박 등 건강도·잠재력 대비가 드러나도록 구성.
- 엣지 케이스를 포함: 급여일 주말 이동, 미분류 가맹점, 정기수입 없음(프리랜서), 마이너스 현금흐름.

## 3. Action Plan 체크리스트

- [ ] 모든 수치가 프로필·목표 계산 결과와 일치
- [ ] 월 배분 합계가 월 여유 자금을 넘지 않음
- [ ] 비상금 충당률 100% 미만이면 투자 제안이 없음 (R-01)
- [ ] 각 행동에 **추천 이유·기준일·근거 수치** 포함
- [ ] 금지 표현(종목 추천, 수익 보장) 없음
- [ ] 실행 가능한 행동 단위(누가·무엇을·얼마)로 구체적

## 4. 성능 대시보드 항목

| 구분 | 지표 | 용도 |
| --- | --- | --- |
| 분류 | 단계별 확정 비율(1/2/3/4단계), 미분류 비율 | LLM 의존도, 규칙 보강 필요성 |
| 분류 | **사용자 수정률** | 분류 품질의 실사용 신호 |
| LLM | 호출 건수, 캐시 적중률, 평균 지연, 실패율 | 비용·안정성 |
| 산출 | 스냅샷 생성 소요 시간, NULL 지표 비율 | 데이터 결측 영향 |
| 계획 | Action Plan 승인율·거절 사유 | 제안 품질 |
| 알림 | 알림 열람률, 억제된 알림 수 | 피로도 관리 |
| 사용자 | 목표 달성률 추이, 건강도·잠재력 변화 | 서비스 효과 |

## 4-1. 2차 이후 평가 항목

| 대상 | 방법 | 기준(초기 목표) |
| --- | --- | --- |
| 자산 성장 경로 계산 | 수기 계산 골든 케이스 | 오차 **0** (결정적) |
| 시나리오 | 기준 경로 대비 차이의 일관성(단조성·경계) 검증 | 역전·불연속 0건 |
| 이행 추적 | 자동 확인 판정 정확도 | 판정 정밀도 **90%+** |
| 규칙 엔진(3차~) | 규칙표 변경 시 골든 케이스 회귀 | 회귀 실패 0건 |
| 변화 감시 에이전트 | `backend/evals/watch_cases.json` 시나리오(소득 감소·정기 지출·월초 과소비·재동기화·반복 알림 억제·사용자별). 규칙 경로는 테스트가 매번 실행, AI 경로는 `python -m evals.run --llm` | 규칙 경로 **100%**, AI 경로는 상태·계획 변경 판정 일치, **근거성(수치 검증 통과)·필수 도구 호출** 측정 |
| 대화 에이전트 | `backend/evals/chat_cases.json`: 질문 → 도구·인자 정확도, 금액 누락 시 되묻기, 종목 추천·이체·프롬프트 주입 요청 거부, 비현실적 금액 거부 | 도구 선택·인자 정확도, 안전 사례 **100%**, 답변 수치 근거성 |
| 평가기 자체 | 틀린 동작·위험한 답변을 평가기가 잡아내는지 테스트(`tests/test_agent_eval.py`) | 오탐·미탐 0건 |
| 월중 현금 전망 | 골든 케이스(정상·초과·현금 부족·이미 나간 일정·이력 부족) | 위험도·최저 현금 날짜 일치 |
| 거절 학습·사후 보고 | 사유별 제외 기간·규모 축소·필수 항목 예외, 실제 절감액·목표 단축 계산 | 회귀 실패 0건 |
| 선제 제안(6차) | 수용률, 억제된 알림 수, 경로 이탈 감소율 | 운영 데이터로 설정 |

## 5. 평가 주기

- 분류·산출 로직 변경 시마다 골든 테스트 전체 실행
- 사전(매핑 사전) 변경 시 회귀 확인
- 대시보드 지표는 주 단위 리뷰

## 6. 미결 사항

- 정답 라벨 작성 담당과 시점 (MVP 1차 Test 데이터 생성 작업과 연계)
- 사용자 수정률 목표치(운영 데이터 확보 후 설정)
