# 금융 전략 제공

## 목적

단순 추천이 아닌 실행 가능한 전략(Action Plan) 제공

---

## 주요 기능

- Action Plan 생성
    - 저축 금액 조정
    - 소비 절감 제안
    - 카드 변경 제안
    - 대출 상환 순서
    - 예·적금 변경
    - 투자 비중 조정
- 추천 근거 제공
    - 왜 추천하는지 설명
    - 사용자 상황 기반 설명
    - 상품 비교
- What-if Simulation
    - 2차 통합 플래너의 시나리오 엔진으로 제공
    - ex) 중간에 여행을 가면? 저축을 늘리면? 등의 상황을 가정

---

## 출력

- Action Plan
- 추천 이유
- 예상 결과
